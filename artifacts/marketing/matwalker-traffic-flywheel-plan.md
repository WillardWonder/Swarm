# MatWalker Traffic Flywheel Plan (v1)

## Objective
Build a repeatable loop that turns content + outreach into qualified team-pricing conversations.

## Flywheel Stages
1. **Capture demand**
   - Landing page + clear team/pilot CTA
   - SEO-focused content drafts mapped to buying intent

2. **Convert demand**
   - Waitlist form with qualification fields
   - Event tracking on CTAs and submits

3. **Prioritize leads**
   - CRM scoring based on role, pair_count signal, pilot_interest, timeline
   - Route high-fit leads to approval queue drafts

4. **Activate conversations**
   - Use approval-gated outreach drafts by segment
   - Track reply outcomes and objections in CRM notes

5. **Feed insights back into content**
   - Turn objections into new FAQ/content topics
   - Refine headline/CTA copy from best-performing event patterns

## Weekly Operating Rhythm
- Monday: review KPI baseline + top events
- Tuesday: publish/prepare 2 new content drafts
- Wednesday: add 5 high-fit leads to CRM
- Thursday: refresh outreach approval queue with 3 tailored drafts
- Friday: update playbook with wins/losses and copy changes

## Channel Buckets (internal planning only)
- Owned: site pages, FAQ, content library
- Direct: approval-gated email/DM templates
- Referral: coach-to-coach mention prompts (future)

## Lead Quality Heuristic
- High: Coach/Director + pair_count present + pilot_interest=yes + <60 day timeline
- Medium: Role fit + missing one of pair_count/timeline
- Low: Individual interest with no program buying signal

## Assets Already in Place
- Waitlist conversion form + qualification fields
- Outreach approval queue with segment-specific drafts
- CRM field dictionary + pipeline definitions
- Event tracking spec + KPI baseline CSV

## Next 5 Improvements
1. Add lead-score field to CRM schema for prioritization
2. Create objection library from notes (price, durability, sizing)
3. Draft 5 title/meta variants for homepage A/B
4. Build `/teams` and `/pilot` page copy stubs
5. Add weekly growth review template in dashboard-data
